## 📖 Project Overview

The Banking Application web application provides a service for core banking operations. It supports creating and managing customer accounts, performing deposits and withdrawals, transferring funds between accounts, and retrieving transaction history.

This project was built as part of a Master of Information Technology program at RMIT University, demonstrating skills in MVC web application development, database integration, and cloud deployment.

---

## 🛠️ Tech Stack

| **Framework** | ASP.NET Core Web API (.NET 10) |
| **Language** | C# |
| **ORM** | Entity Framework Core |
| **Database** | PostgreSQL (hosted on [Neon](https://neon.tech)) |
| **Cloud Hosting** | Azure App Service (Free Tier) |
| **API Docs** | Swagger / OpenAPI |
| **Version Control** | Git & GitHub |
