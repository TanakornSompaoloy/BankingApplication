\# 🏦 Banking Application API



A MVC Web Application for banking operations including accounts, transactions, and balances — built with ASP.NET Core and deployed on Azure.

> \*\*Web Base URL:\*\* https://bankingapp-bqgvdvfvfse6eyd0.australiaeast-01.azurewebsites.net/



---



\## 📖 Project Overview



The Banking Application provides a service for core banking operations. It supports creating and managing customer accounts, performing deposits and withdrawals, transferring funds between accounts, and retrieving transaction history.



This project was built as part of a Master of Information Technology program at RMIT University, demonstrating skills in MVC web application development, database integration, and cloud deployment.



---



\## 🛠️ Tech Stack



| Layer | Technology |

|---|---|

| \*\*Framework\*\* | ASP.NET Core (.NET 10) |

| \*\*Language\*\* | C# |

| \*\*ORM\*\* | Entity Framework Core |

| \*\*Database\*\* | PostgreSQL (hosted on \[Neon](https://neon.tech)) |

| \*\*Cloud Hosting\*\* | Azure App Service (Free Tier) |

| \*\*Version Control\*\* | Git \& GitHub |
